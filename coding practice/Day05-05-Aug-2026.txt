# Terraform Commands

terraform init
- Initializes Terraform working directory.
- Downloads required provider plugins.

terraform plan
- Shows the execution plan before making changes.

terraform apply
- Creates or updates infrastructure.

terraform apply --auto-approve
- Applies changes without asking for confirmation.

terraform destroy
- Removes all infrastructure managed by Terraform.

--------------------------------------------------------

# Linux Process Management

ps
Displays currently running processes.

ps -e
Displays all running processes.

ps -ef
Shows detailed information about every running process.

ps aux
Shows user, PID, CPU usage, memory usage and command.

top
Interactive system monitoring tool.

htop
Enhanced interactive process viewer.

kill PID
Gracefully terminates a process.

kill -9 PID
Forcefully kills a process.

pkill process_name
Kills processes using the process name.

--------------------------------------------------------

# grep Commands

grep "text" file

Searches for matching text.

grep -i

Case-insensitive search.

grep -v

Displays lines that do NOT match.

grep -w

Matches complete words only.

grep -r

Recursive search inside directories.

grep -E

Extended Regular Expressions.

wc -l

Counts the number of output lines.

# System Monitoring Commands

free -h

# Networking Commands

ping google.com

telnet IP PORT

wget URL

curl URL

# Cron Jobs

crontab -l
List Cron Jobs.

crontab -e
Edit Cron Jobs.

crontab -r
Delete Cron Jobs.

systemctl restart crond
Restart Cron service.

Cron Format

Minute Hour Day Month DayOfWeek

# Bash Scripting Concepts

Variables

VARIABLE="value"

echo $VARIABLE

Comments

# This is a comment

Positional Parameters

$0
Script name.

$1
First argument.

$2
Second argument.

$#
Number of arguments.

$@
All arguments individually.

$*
All arguments together.

Conditional Statement

if [ -f "$FILE" ]
then
    echo "File Exists"
else
    echo "File Not Found"
fi

For Loop

for SERVICE in nginx docker sshd
do
    echo "Checking $SERVICE"
done

# Input & Output Redirection

>

Overwrite output.

>>

Append output.

2>

Redirect standard error.

2>>

Append standard error.

&&

Runs next command only if previous succeeds.

|

Pipe output from one command to another.
