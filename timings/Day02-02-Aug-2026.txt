## Hard Link vs Soft Link

Hard Link
- Points directly to the inode.
- Remains valid even if the original filename is deleted.
- Increases the file's link count.

Soft Link (Symbolic Link)
- Acts like a shortcut.
- Points to the file path.
- Breaks if the original file is deleted or renamed.
