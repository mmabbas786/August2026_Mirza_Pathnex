# Commands Practiced

System Information

hostname
lscpu

User Management

cat /etc/passwd
getent passwd
getent passwd | wc -l
who
sudo useradd <username>

id <username>
sudo usermod -aG wheel <username>

SSH

ssh <username>@<server-ip>

Service Management

sudo systemctl restart sshd

Ownership

sudo chown <username> <filename>
sudo chown <username>:<groupname> <filename>

sudo chgrp <groupname> <filename>

Permissions

umask

Disk Usage

df -h

File Editing

sed -i '$r filename' filename
cp app.conf app.conf.bak_$(date +%F)

Archiving

tar -cvzf app.tar.gz app

# Key Takeaways

- Always work as a normal user and use sudo only when required.
- SSH key-based authentication is more secure than password authentication.
- Bastion Hosts improve infrastructure security.
- Understanding file ownership and umask is essential for Linux administration.
- Always create a backup before modifying important configuration files.
- Regularly stop or terminate unused AWS resources to avoid unnecessary costs.
