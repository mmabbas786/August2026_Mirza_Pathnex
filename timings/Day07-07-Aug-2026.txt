# Key Takeaways

- EC2 provides scalable virtual servers.
- IAM controls access using users, groups, roles, and policies.
- Least-privilege access should be preferred.
- VPC provides isolated AWS networking.
- Public and private subnets separate internet-facing and internal workloads.
- S3 provides scalable object storage.
- CloudTrail focuses on AWS API auditing.
- CloudWatch focuses on monitoring, metrics, logs, and alarms.
- Session Manager can provide secure EC2 access without opening inbound SSH/RDP.
- AWS lab resources should be cleaned up to avoid unnecessary charges.
