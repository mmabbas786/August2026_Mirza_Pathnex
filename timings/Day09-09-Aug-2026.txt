# Key Takeaways

- Shield protects against DDoS attacks.
- WAF protects web applications and APIs against common Layer 7 attacks.
- XSS targets the client/browser while SQL Injection targets the database through unsafe application input.
- GuardDuty detects suspicious activity but is primarily a detection service.
- Inspector identifies vulnerabilities in supported AWS workloads.
- CVE identifies a known vulnerability while CVSS provides a severity score.
- When vulnerabilities have similar severity, business and customer impact can help decide priority.
- EventBridge routes events between services and applications.
- SNS is mainly used for publish/subscribe notifications.
- SQS provides a queue for asynchronous communication and decoupling.
- KMS manages cryptographic keys used for encryption.
- Systems Manager provides centralized operational management.
- SQL databases use structured tables and predefined schemas.
- NoSQL databases provide flexible data models and are designed for large-scale distributed workloads.
- RDS provides managed relational databases, while DynamoDB is a managed NoSQL service.
- Aurora is an AWS relational database engine compatible with MySQL and PostgreSQL.
