# Key Takeaways

- Landing Zone provides a structured multi-account AWS foundation.
- Control Tower helps automate and govern the Landing Zone.
- SCPs restrict maximum permissions across AWS accounts.
- S3 Versioning helps recover from accidental overwrites and deletions.
- Session Manager provides secure EC2 access without requiring inbound SSH port 22 or a public IP.
- Route 53 provides DNS and traffic-routing capabilities.
- CloudFront uses edge locations to deliver content closer to users.
- Tags help identify ownership, environment and temporary resources.
- CloudTrail focuses on AWS API auditing.
- CloudWatch focuses on monitoring, metrics, logs and alarms.
- Auto Scaling uses minimum, desired and maximum capacity.
- Lambda is event-driven and has a maximum execution limit.
